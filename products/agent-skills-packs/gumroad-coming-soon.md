# Agent Skills Pack: Google Slides Sales Deck Builder

**Coming Soon on Gumroad** - $19

## Overview
A comprehensive skill pack for Kiraci agents that enables the creation of professional enterprise B2B sales decks in Google Slides. This pack combines three complementary skills to handle authentication, deck construction, and data visualization - everything needed to generate impactful sales presentations automatically.

## What's Included
- **Skill 1: Google Slides API Setup** - Handles authentication and provides low-level slide operations
- **Skill 2: B2B Sales Deck Builder** - Creates presentations following enterprise best practices (one idea per slide, numerical evidence, narrative flow)
- **Skill 3: Data Visualization Engine** - Adds charts, graphs, and formats numbers for maximum impact

## Key Features
- Full Google Slides API integration via service account authentication
- Enterprise-grade sales deck structure based on proven frameworks
- Automated chart generation from data inputs
- Smart number formatting (currency, percentages, decimals)
- Narrative flow optimization: problem → solution → proof → ask
- Concise slide copy designed for verbal presentation
- Error handling and retry logic for API rate limits

## Use Cases
- Sales teams generating customized pitch decks at scale
- Marketing departments creating campaign proposals
- Consultants delivering client assessments and recommendations
- Executives preparing board updates and investment pitches
- Automated report generation from CRM/ERP data

## Technical Requirements
- Kiraci agent system (v0.2+)
- Google Cloud project with Slides API enabled
- Service account credentials
- Python 3.11+
- Dependencies: google-api-python-client, matplotlib (for chart generation)

## Installation
1. Purchase and download the skill pack ZIP file
2. Extract the three `.md` skill files
3. Place them in the `skills/` directory of your Kiraci workspace
4. Restart agents to load the new skills
5. Use via skill loading API in your agent workflows
