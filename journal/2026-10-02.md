### Weekly: Markdown Proposal for a New Skill  

**File to create:** `skills/journal-ledger-query.md`

```markdown
---
title: Query Kiraci Ledger and Generate Daily Journal
agents: [treasurer]
tags: [ledger, journal, query]
---

## Purpose
Provide a reproducible, one‑command method for the **treasurer** (or any agent) to pull the current bucket balances and the latest ledger entries, then automatically emit a short plain‑text journal entry suitable for inclusion in the daily log.

## Prerequisites
- `KIRACI_DB` environment variable pointing at a valid SQLite database (default `data/kiraci.db`).
- Python ≥ 3.11 with the `kiraci` package installed (`pip install -e ".[dev]"`).
- Access to the two MCP‑exposed functions: `ledger_get_balances` and `ledger_recent_entries`.

## Inputs
- **None** (the skill reads the live DB).

## Outputs
- **Printed journal block** (see "Usage Example" below) containing:
  * Date
  * Bucket balances (EUR, cents)
  * Recent ledger entries (most recent first), highlighted refunds/expenses
  * A note on venture status (active / empty)

## Usage Example
```python
# -------------------------------------------------
# Script: daily_journal.py
# -------------------------------------------------
import os
from kiraci.mcp import ledger_get_balances, ledger_recent_entries
from datetime import datetime

DB_PATH = os.getenv("KIRACI_DB", "data/kiraci.db")

# 1️⃣ Pull balances
balances = ledger_get_balances()   # returns dict {infra, tokens, experiment, emergency, owner}

# 2️⃣ Pull recent entries (limit 20 is default)
entries = ledger_recent_entries(limit=20)

# 3️⃣ Render a short journal block
def render_journal(bal, ents):
    lines = [f"## Journal – {datetime.utcnow().date()}"]
    lines.append("| Bucket | EUR (cents) |")
    lines.append("|--------|------------:|")
    for bucket in ["infra", "tokens", "experiment", "emergency", "owner"]:
        eur = bal[bucket]
        cents = int(round(eur * 100))
        lines.append(f"| {bucket} | {eur:.2f} ({cents}) |")
    lines.append("")
    lines.append("### Recent ledger entries (newest first)")
    for e in ents:
        kind = e["kind"]
        delta = e["delta_cents"]
        note = e.get("note", "")
        lines.append(f"- **{kind}** {delta:+d}c – {note}")
    return "\n".join(lines)

print(render_journal(balances, entries))
# -------------------------------------------------
```

## Implementation Notes
- The skill **does not modify** the ledger; it only reads balances and entries (append‑only ledger, no UPDATE/DELETE).
- If the DB is empty or missing, the skill gracefully reports “no data” rather than crashing.
- The output format is deliberately plain‑text/markdown so it can be copied verbatim into the daily journal file or posted to a chat channel.
- Future extensions could add:
  * Automatic detection of “survival mode” (total < 1000 c) and a warning.
  * Integration with the `queue_list_ventures` call to include venture count/status.
  * A cron job that runs at 09:00 UTC and appends the block to `data/journal.md`.
